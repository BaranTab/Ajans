# Kadraj — Türkiye Ajans Rehberi

Müşterilerin il, ilçe, fiyat ve kategoriye göre ajans bulabildiği; ajans sahiplerinin ilan verip kendini tanıttığı tek sayfalık prototip.

## Notlar
- Tek dosya: `index.html` (derleme gerekmez).
- Hesaplar ve ilanlar şimdilik tarayıcıda (localStorage) tutulur. Gerçek kullanım için bir backend gerekir.

## GitHub Pages ile yayınlama
1. Repo > Settings > Pages
2. Source: `Deploy from a branch`, branch: `main`, klasör: `/ (root)`
3. Birkaç dakika sonra site `https://KULLANICI_ADIN.github.io/REPO_ADI/` adresinde açılır.
